## 1. Rhost 是什么

**Rhost** 是一款基于 Rust + Tauri 2 开发的开源桌面远程主机管理器，提供 SSH 终端、SFTP 文件管理、端口转发与服务器监控等能力，并自 v2.0.0 起内置 **AI 助手**，支持 macOS / Windows / Linux。

一句话：**用更低的内存占用和更流畅的多连接体验，管理你的远程服务器。**

## 2. 解决什么问题

传统 Electron 类终端工具在大量终端输出时存在 JSON 序列化开销大、ANSI 内容损坏、多连接并发卡顿、内存占用高等问题。Rhost 采用**原生二进制 IPC 流**架构：

- 终端高频字节流走自定义二进制帧 Channel，不经 JSON 序列化
- 低频控制消息走 invoke/JSON
- 每会话独立 IPC Channel，数据流完全隔离

从而规避序列化开销与内容损坏，实现高并发下的流畅体验。

AI 助手沿用同一隐私边界：终端内容不会以任何自动形式离开本机，仅用户显式选中并主动发送的内容会随对话上传；AI 模块设置（含 API 密钥）不参与配置导入导出。

## 3. 核心能力

| 能力 | 说明 |
|---|---|
| 内置 AI 助手 | 流式对话、推理可视化、Markdown / 代码块渲染与一键插入终端；图片与文本附件多模态输入；会话按视图隔离 |
| Plan-and-Act 任务规划 | 模型自主起草计划，确认后分步执行并实时展示步骤状态；失败可重试/跳过/终止/重新规划，支持提前收敛 |
| 工具授权与风险控制 | 只读工具免授权自动执行；命令提案、文件编辑与 SFTP 传输经授权弹窗裁决，内置高危命令检测与关键路径保护 |
| 技能、规则与记忆 | 本地 Markdown 文件注入领域知识与行为约束，跨会话记忆自动沉淀，注入预算与开关可控 |
| 多标签 SSH 终端 | xterm.js 渲染、UTF-8 全链路透传、右键菜单、多会话广播 |
| 断线自动重连 | 网络意外中断触发指数退避重连（1s 起翻倍、封顶 30s），手动断开不重连 |
| SFTP 文件管理 | 双栏浏览、流式传输队列、断点续传、暂停/取消 |
| 端口转发 | 本地/远程/SOCKS5 动态转发，状态实时推送与流量统计 |
| 服务器监控 | CPU/内存/磁盘/网络/进程/GPU 周期指标，零 sudo、零远端落盘 |
| 主机密钥校验 | TOFU 首次信任 + known_hosts 持久化，密钥变更弹红色警告 |
| 安全凭证存储 | 密码/私钥口令存入系统密钥环，绝不写入配置文件 |
| 配置导入导出 | 整体配置与主机列表批量导入导出，导入后一键重启生效 |

## 4. 特性清单

- 🤖 内置 AI 助手，流式对话 + 推理可视化 + 代码块一键插入/执行
- 🧭 Plan-and-Act 任务规划，分步执行与失败重试/跳过/终止/重新规划
- 🛡️ 工具授权与风险控制，只读免授权、写操作弹窗裁决、高危命令检测
- 🧠 技能、规则与跨会话记忆注入，注入预算与按文件开关
- 🖼️ 多模态输入，选择 / 粘贴 / 拖拽添加图片与文本文件
- 🖥️ 多标签 SSH 终端，每会话独立 IPC Channel
- ♻️ 断线自动重连，区分断线原因
- 📁 内置 SFTP 文件管理器，支持断点续传
- 🔗 SSH 端口转发（本地/远程/SOCKS5）
- 📈 服务器监控（MOTD + 周期指标）
- 🔐 主机密钥校验，防中间人攻击
- 🔑 系统密钥环安全存储凭证
- 📂 主机分组、备注、快速连接
- 📤 配置导入导出
- 📝 应用日志系统
- ⚡ 纯异步 Rust 内核，UI 永不阻塞
- 🎨 Tauri 原生桌面，体积小、内存低

## 5. 适用场景

| 场景 | 说明 |
|---|---|
| 运维工程师 | 管理多台服务器，批量执行命令，传输文件，排查线上故障 |
| 开发者 | 远程开发、调试、部署，查看服务器资源 |
| 个人用户 | 管理 VPS、家庭服务器、NAS 等 |
| 需要多连接并发的用户 | 同时操作多台主机，广播命令，监控资源 |
| AI 辅助运维的用户 | 用自然语言让 AI 在授权范围内执行命令、编辑文件、规划复杂任务 |

## 6. 技术栈

- **后端**：Rust（edition 2024）+ Tokio 全异步 + russh + russh-sftp + keyring
- **AI 能力**：自主封装 OpenAI 兼容协议（JSON + SSE 流式 + tool calls + 技能/规则/记忆注入），不依赖第三方 Agent 框架
- **前端**：Vue 3.5 + TypeScript + Vite + Xterm.js
- **桌面框架**：Tauri 2
